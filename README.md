# REWIND.exe

> *"You can't change the past. But you can make it repeat."*

A short experimental 2D puzzle game made for **Ludum Dare (theme: Old Tech)** in Unity.
An operator follows a strange signal to **Complex 07**, an abandoned analog bunker, and must restart
its **lifecycle system** by restoring four sectors — using old terminals, codes and magnetic tape.

**Status:** work in progress (art, audio, rooms, terminal, intro and the three endings are in; quests are being added).

## Play it in the editor

1. Open the project with **Unity 6000.6.6f1** (Unity Hub → Add → this folder).
2. Open `Assets/Scenes/Intro.unity` and press **Play** (or `SampleScene` to skip the intro).

| Action | Keys |
|---|---|
| Use computer / door / note | Mouse click, or hover + **E** |
| Next dialog line | **Space / Enter / click** |
| Skip cutscene | **Esc** |
| Close terminal | **Esc** or `EXIT` |

Terminal commands: `HELP`, `STATUS`, `HINT`, `LOG`, `VOLUME`, `MUTE`… each computer can add its own (codes!).

## Endings

| Ending | How |
|---|---|
| **Good — Lifecycle Mode** | Restore all 4 sectors, then `RESTART CYCLE` on the main computer |
| **Fail — Life support failure** | `RESTART CYCLE` fails 3 times |
| **Bad — Kill protocol** | `OVERRIDE` at the Core terminal |

## For developers

- **Tools → REWIND.exe → Dev Tools** (`Ctrl+Shift+D`): play the intro or any ending from edit mode, jump between rooms,
  restore sectors, unlock doors, auto-play/skip cutscenes, reset the attempts counter.
- Terminal cheats (Editor / development builds only): type `DEV` in any terminal.
- Cutscenes are lists of editable steps on each scene's **CutsceneDirector** (dialog, camera, sounds, fades…).
- Quest hooks: a `TerminalCommand` (e.g. `UNLOCK 4471`) → *On Execute* → `LifecycleProgress.RestoreSector(n)`,
  `RoomExit.Unlock()`, or `EndingTrigger.PlayFail / PlayBad / PlayGood`.

### Generated content

All pixel art and audio are generated by scripts, so they can be tweaked and rebuilt:

```bash
python Tools/ArtGen/generate_art.py          # sprites + art_manifest.json (Unity slices & animates them on import)
python Tools/AudioGen/generate_audio.py      # sound effects, ambience loops and music (WAV)
```

Requires Python 3 with `Pillow` (art) and `numpy` (audio).

## Project layout

```

  Audio/      generated SFX, ambience and music
  Scenes/     Intro, SampleScene (the 4 rooms), Ending_Fail / Ending_Bad / Ending_Good

Tools/        art and audio generators (Python)
```
